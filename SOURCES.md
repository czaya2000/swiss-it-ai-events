# Event sources

Sites the daily refresh routine checks for new or changed Switzerland IT/AI events.
Add a line any time you find a source worth watching — the next morning's run picks
it up automatically. One source per line; a short note after `—` is optional.

Every event still gets verified against its own original page before being listed —
adding a source here means "check this for leads," not "trust it blindly."
