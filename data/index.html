Data & feeds

The event list is free to use in apps, newsletters, calendars and AI assistants. Everything below is rebuilt every Monday, Wednesday and Friday morning with the site. Only upcoming events are included. Please link to the event's page on Swiss Data Events when you reuse a listing.

Endpoints

  • /events.json: every upcoming event as JSON.
  • /rss.xml: RSS feed, newest listings first.
  • /llms.txt: a markdown summary for AI agents, with every upcoming event.
  • /calendar/all.ics: iCalendar feed to subscribe to.

Fields in /events.json

id
Stable identifier. Never changes, even if the title or date is corrected.
title
Event name as the organiser publishes it.
start, end
ISO 8601. A date-time with the Zurich offset (e.g. 2026-10-29T17:30:00+01:00) when the time is known, otherwise a date.
allDay
True when start and end are plain dates.
dateLabel, time
Human-readable date range and the original time text.
city, region
The exact place, and the main city it belongs to (e.g. Schlieren → Zurich).
online
True for online-only events.
venue
Venue name, or null.
format
One of Meetup, Conference, Workshop, Networking, Webinar.
topics
Short topic tags.
cost, free
Price as published, and whether it is free.
organiser
Who runs the event.
description
One-sentence summary written by us.
url
The event page on this site.
registrationUrl
The organiser's page, where people register.
verifiedVia
Where the details were checked.
firstSeen
Date the event was first listed here.
calendarFeed
iCalendar feed for the event's city.

Notes

Every listing is checked against the organiser's own page, but details can change on their side, so point people to the organiser's page before they go. Fields may be added over time; existing ones are not renamed or removed without changing version.
